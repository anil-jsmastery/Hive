# Pull request description writer

Writes a pull request description that explains what changed, why and how to test it.

## When to use

Use this skill when opening a pull request and you want reviewers to understand it quickly.

## Steps

1. Read the diff and the related issue.
2. Summarize the change in two sentences: what and why.
3. List the notable changes reviewers should look at first.
4. Write exact steps to test the change.
5. Note risks, follow-ups and anything deliberately left out.

## Output

A pull request description with Summary, Changes, How to test and Notes.
