# README writer

Writes a README that gets a new developer from clone to running app in minutes.

## When to use

Use this skill when a project has no README, or one nobody can follow.

## Steps

1. Say what the project does in one sentence.
2. List prerequisites with exact versions.
3. Write the setup commands in the order they must run, and test them.
4. Explain the environment variables and where to get each value.
5. Add how to run tests and where to ask for help.

## Output

A README.md with Overview, Setup, Configuration, Testing and Support.
